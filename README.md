# GhostPilot

폰에 말하면 AI가 컴퓨터를 직접 조작합니다. 컴퓨터에는 아무것도 설치하지 않고, 작은 USB 장치 하나로.
*Tell your phone, and AI operates your computer through a small USB device. Nothing is installed on the computer.*

이 저장소는 **다운로드 전용**입니다. 앱·PC 브리지·펌웨어는 [Releases](../../releases)에서 받으세요.
*This repository is for downloads only: get the app, the PC bridge and the firmware from [Releases](../../releases).*

| 받을 것 / Download | 설명 / What it is |
| --- | --- |
| `GhostPilot-full-*.apk` | 직접 설치판 — 폰 안에서도 Claude Code·Codex 실행 / Direct-install build, runs Claude Code and Codex on the phone too |
| Google Play | 플레이판 — 컴퓨터 브리지·API 키로 사용 (준비 중) / Play build, uses the computer bridge or API keys (coming) |
| `ghostpilot_bridge.py` | PC 브리지 — 내 컴퓨터의 Claude Code·Codex를 폰에 연결 (Python 3.9+) / Connects Claude Code or Codex on your computer to the phone |
